VinMind プライバシーポリシー

最終更新日: 2026年9月6日

VinMind（以下「本アプリ」）は、あなたの記録をあなたの端末の中に置いたまま使えるように設計されています。 本ポリシーは、本アプリが何を扱い、何を扱わないかを説明します。

1. アカウントを作りません

本アプリはユーザー登録を必要としません。氏名・メールアドレス・電話番号・生年月日・住所を 一切収集しません。ログイン機能はありません。

2. 端末の中だけに保存されるもの

以下はすべて端末内のデータベースとファイルに保存され、あなたが操作しない限り端末の外に出ません。

  • テイスティング記録（外観・香り・味わい・結論・評価・メモ）
  • ワインの情報とラベル写真
  • ブラインドの推論・正解・採点結果
  • 香りの語彙のユーザー編集内容、あなたが追加した表現
  • 学習の進捗、クイズの履歴、アプリの設定と表示言語

3. AI 機能を使ったときに送信されるもの

AI による助言・ラベル読み取り・香りの逆引き・チャット・ヒント・香りアイコン生成を使うと、 その処理に必要な内容が当社のサーバー（Cloudflare Workers）を経由して OpenAI, L.L.C. の API に 送信されます。AI 機能を使わなければ送信は発生しません。

送信されるもの

  • その操作の対象になっている記録の内容（外観・香り・味わい・結論、ブラインドの推論と正解）
  • ラベル読み取りを使った場合はその写真
  • あなたが入力した自由文（チャット、香りの逆引き）
  • 表示言語の設定
  • 後述の匿名利用者ID

送信されないもの

  • 上記以外の記録、写真、連絡先、位置情報、端末の識別子

当社サーバーでの保存

当社サーバーは送信内容と AI の応答を保存しません。保存するのは AI 利用枠の管理に必要な 台帳（匿名利用者IDごとの利用量、有料プランの状態、購入の重複付与を防ぐための取引ID）だけです。 稼働ログには利用量・費用・匿名利用者ID、および失敗時のエラー内容（最大300文字）が残りますが、 記録の本文や写真は残りません。

OpenAI での取り扱い

OpenAI の API を経由して送信されたデータは、OpenAI のポリシーにより既定でモデルの学習には 使用されません。不正利用の監視のために一定期間（最大30日）保持される場合があります。

4. 匿名の利用者ID

AI の利用量を数えるために、購入管理サービス（RevenueCat, Inc.）が生成する匿名IDを使います。 このIDは氏名やメールアドレスと結びつきません。アプリを削除して再インストールすると別のIDになります。

5. 購入について

App Store 内の購入は Apple が処理します。クレジットカード番号などの決済情報が本アプリに 渡ることはありません。有料プランの判定と「購入の復元」のために、購入とサブスクリプションの 状態を RevenueCat, Inc.（米国）が処理します。

6. IP アドレス

AI 機能の不正利用（無料枠の大量取得や過剰なリクエスト）を防ぐため、AI 機能の呼び出し時に 接続元の IP アドレスを用いて回数を数えます。この数値は協定世界時（UTC）の日付が変わると 消去されます。広告の配信や行動の追跡には使いません。

7. 広告の効果測定

Apple の広告経由でインストールされたかを測るため、Apple が提供する AdServices の帰属トークンを 取得する場合があります。このトークンは広告識別子（IDFA）を使わず、個人や端末を識別しません。

8. 利用状況の計測（オフにできます）

どの画面が使われ、どこで離脱しているかを知るために、利用状況を匿名で計測しています。 処理は PostHog（PostHog, Inc. 米国）に委託しています。

送るもの

  • 画面や機能の利用を表すあらかじめ決めた名前のイベント（例: ペイウォールの表示、 オンボーディングの各ステップの通過、クレジット不足の案内の表示）
  • そのイベントに付く短い識別子だけの値（例: 選んだプランの種類、訴求を出した画面の種類）
  • アプリのバージョン、OS の種類とバージョン、端末の機種名、表示言語、タイムゾーン
  • AI 機能の成否・応答時間・経路（サーバー側で記録します）

送らないもの

  • テイスティング記録の内容、メモ、自由記述、ワイン名、ラベル写真
  • 氏名・メールアドレス・電話番号などの連絡先（そもそも収集していません）
  • 位置情報、広告識別子（IDFA）
  • IP アドレス（サーバー側からの送信では明示的に除外し、アプリからの送信についても PostHog 側で破棄する設定にしています。所在地の推定にも使いません）

識別子について

計測には、端末の中で生成される計測専用の匿名IDを使います。このIDは購入管理の匿名ID （第4項）とは別物で、両者を突き合わせることはしません。サーバー側の記録には、購入管理の 匿名IDをそのままではなく復元できない形に変換した値を使います。

止め方

アプリの「設定」→「プライバシー」→「利用状況の計測」をオフにすると、以後は起動を含めて 一切送信しません。既定はオンです。

9. 行っていないこと

  • 個人情報の第三者への販売・貸与
  • 広告の表示（本バージョンでは広告を配信していません）
  • 他社のサービスをまたぐ行動の追跡

10. バックアップと持ち出し

端末のバックアップ（iCloud など）に本アプリのデータが含まれる場合があります。これは OS の機能で、 その取り扱いは Apple のポリシーに従います。また、あなたの操作で記録を JSON ファイルとして 書き出せます。書き出したファイルの管理はあなたに委ねられます。

11. データの削除

本アプリを端末から削除すると、端末内のデータは削除されます。当社サーバー上の利用量台帳の削除を 希望する場合は、下記の連絡先までご連絡ください。

12. 年齢について

本アプリはアルコール飲料を扱うため、17歳未満の方の利用を想定していません。

13. 本ポリシーの変更

内容を変更する場合は、本ページの最終更新日を改めます。重要な変更はアプリ内でお知らせします。
